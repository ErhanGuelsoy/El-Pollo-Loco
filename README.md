# 🎮 El Pollo Loco – Jump & Run Game

**El Pollo Loco** is a browser-based 2D Jump & Run game developed with **JavaScript, HTML5, and CSS3**.

The player explores a desert environment, jumps over obstacles, defeats enemies, and collects items. The main goal is to reach and defeat the **Endboss**.

---

## 🎯 Gameplay

* 🏃 Move through the game world
* 🦘 Jump over obstacles and enemies
* 🐔 Defeat enemies
* 🪙 Collect coins
* 🍾 Collect and throw bottles
* 👹 Fight the Endboss
* 📱 Play on desktop and mobile devices

---

| Technology            | Usage                                |

---

## 🎮 Controls

| Key     | Action            |
| ------- | ----------------- |
| `←` `→` | Move left / right |
| `SPACE` | Jump              |
| `D`     | Throw bottle      |

> 📱 **Mobile:** Touch controls are available in mobile mode.

---

## 🧱 Object-Oriented Programming

The game was developed using **Object-Oriented Programming (OOP)**.

Characters, enemies, collectible items, bottles, status bars, and other game elements are organized into separate classes.

This approach makes the code:

* **Structured**
* **Reusable**
* **Maintainable**
* **Easy to extend**

---

## 📱 Responsive Design

The game supports different screen sizes and includes a dedicated **mobile mode** with touch controls.

The mobile version is optimized for **landscape orientation** to provide a comfortable gaming experience on smartphones and tablets.

---

## 🏆 Game Goal

Reach the **Endboss**, survive the final battle, and defeat him to complete the game.
