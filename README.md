El Pollo Loco – Jump & Run Game

El Pollo Loco ist ein browserbasiertes 2D Jump & Run Spiel mit JavaScript, HTML und CSS.

Der Spieler bewegt sich durch die Spielwelt, springt über Hindernisse, besiegt Gegner und sammelt Gegenstände. Ziel ist es, den Endboss zu erreichen und zu besiegen.

🛠️ Technologien
HTML5 / CSS3
JavaScript
Canvas API
Object-Oriented Programming (OOP)
Responsive Design
